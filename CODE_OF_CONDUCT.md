# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## The short version

- Be kind. Disagree about ideas, not people.
- Cite sources, not opinions.
- No fabricated facts. Ever.
- Default to assuming good intent.
- Report unacceptable behavior to the maintainers via a private issue.

## Enforcement

Maintainers will remove contributions and contributors that violate this code. Repeat violations result in a ban.
