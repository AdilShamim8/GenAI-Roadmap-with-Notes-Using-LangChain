# Books

> Verified 2026-07-30.

- [Designing Machine Learning Systems — Chip Huyen](https://www.oreilly.com/library/view/designing-machine-learning/9781098107956/) — Best systems-thinking ML book. Applicable to LLM systems.
- [AI Engineering — Chip Huyen](https://www.oreilly.com/library/view/ai-engineering/9781098166298/) — The 2025 book. Most comprehensive survey of production GenAI engineering.
- [Natural Language Processing with Transformers — Tunstall, von Werra, Wolf](https://www.oreilly.com/library/view/natural-language-processing/9781098136796/) — HuggingFace team. Good for foundations.
- [Hands-On Large Language Models — Jay Alammar, Maarten Grootendorst](https://www.oreilly.com/library/view/hands-on-large-language/9781098150952/) — Strong visual explanations.
- [Prompt Engineering for LLMs — O'Reilly](https://www.oreilly.com/library/view/prompt-engineering-for/9781098156299/) — Reference for prompt patterns.
- [Building LLM Powered Applications — Valentina Alto](https://www.packtpub.com/product/building-llm-powered-applications/9781835086551) — Practical intro.
